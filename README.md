# Prerna Collective

A responsive React frontend for mission-first storytelling across venture capital, philanthropy, fellowships, community programs, and careers.

![Prerna Collective screenshot](screenshot.png)

## Features

- React Router pages with lazy-loaded route components.
- Fixed header with local logo, theme toggle, and accessible navigation drawer.
- Responsive pages for work, collective programs, legal content, careers, and contact.
- Reusable styled-components theme tokens and a floating back-to-top control.
- Icon-only social and support links in the footer.
- GitHub Pages deployment with route-aware metadata.

## Tech stack

React, Vite, React Router, styled-components, React Icons, MUI, Zustand, Recharts, Dexie, and local public assets.

## Run locally

```bash
npm install
npm run dev
```

Validate, build, and deploy:

```bash
npm run lint
npm run build
npm run deploy
```
